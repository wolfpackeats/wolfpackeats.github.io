# Raleigh Wolf Bites

Raleigh Wolf Bites is an independent student restaurant guide for places near NC State University.

The site currently includes 110 active listings, price and closing-time sliders, campus starting points, food-fit and open-now filters, compact browsing, a random restaurant picker, and links that open current walking directions in Google Maps.

This project uses original geometric artwork and an independent teal, coral, gold, and cream visual identity. It is not affiliated with, sponsored by, or endorsed by NC State University or any listed restaurant. Restaurant names and trademarks identify their respective businesses.

Live site: https://wolfpackeats.github.io/
